## 기술 계약과 시연 범위

공통 계획의최근 입력규칙을 따른다. 실제숫자가바뀐ENTER_DIGIT만갱신하며메모/no-op/선택이동/옵션변경은제외한다.
최근칸의숫자 삭제→null,다른칸삭제→유지. 새 게임·초기·완료→null. lastInputIndex는null또는현재 값있는편집셀이다.
선택한칸이바뀌어도최근 입력은남는다. 상태를DOM에서추측하거나강조용timeout을등록하지 않는다.
012/013은이필드를명시적으로복원하지만이태스크에서미래history/저장소는구현하지 않는다.

예정 변경 위치: game-state.ts의lastInputIndex·board.ts의표시모델·CSS·수동fixture·상태/렌더회귀.
아래 위치·명령은 구현 시 실제 파일/설정에서 확인하며 없는 파일을 이미 존재하는 것으로 보고하지 않는다.
