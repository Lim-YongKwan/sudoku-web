## 3. 작업 범위와 계약

포함: lastInputIndex와 타입/런타임 불변조건, 순수 상태 전이, 셀 표시·접근성, 회귀 검사·개발 fixture.

- 실제 값이 달라진 ENTER_DIGIT만 최근 입력을 갱신한다. 동일값·메모·단서 입력·선택/이동·보조 옵션 변경은 제외한다.
- 최근 칸의 실제 숫자 삭제 → null, 다른 칸 숫자/메모 삭제 → 유지.
- 초기·새 게임·생성 성공/실패·완료 → null. lastInputIndex는 null 또는 현재 숫자가 있는 편집 셀이다.
- 선택 이동 후에도 유지한다. DOM에서 상태를 추측하거나 강조용 timeout을 등록하지 않는다.
- 단서·충돌·선택·포커스 구분과 불변 상태·DOM 독립 core·외부 폼 키 정책을 보존한다.
- 런타임 외부 라이브러리·CDN·번들러를 도입하지 않는다.

제외: 시간 기반 해제, 메모를 최근 숫자로 처리, 정답/후보 힌트, 011 같은 숫자 강조, 012 실행 취소, 013 저장. 012/013은 향후 이 필드를 검증·복원한다.
