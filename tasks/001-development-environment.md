## 3. 작업 범위

### 포함

- Node.js 22 이상 실제 실행 경로와 npm·브라우저 도구 확인. 현재 PATH v16.20.2의 기준 미충족 해결을 환경 준비 항목으로 다룬다.
- package.json(type: module), scripts/serve.mjs, 최소 index.html·src/main.js·styles/main.css, tests/server.test.js를 작성한다.
- 루프백 정적 서버, HTML·JS·CSS MIME, 없는 파일·경로 이탈 요청·포트 오류·종료 처리를 구현한다.
- README의 실제 실행 방법·환경 조건과 architecture.md의 현재 구조를 갱신한다.

### 제외

스도쿠 엔진·보드·입력·타이머·게임 UI. 외부 패키지 설치, 번들러 도입, 승인 없는 시스템 Node 교체·환경 설정 변경.

### 유지할 제약

- 외부 의존성과 번들러를 추가하지 않는다. 계획의 계약·단서·유일해·입력 불변·상태 경계를 유지한다.
- 다른 담당자의 변경을 보존하며, 선행 코드가 없는 경우 후속 기능을 임의로 합쳐 구현하지 않는다.

## 기술 계약과 시연 범위

- npm start → node scripts/serve.mjs, npm test → node --test를 실제로 구성한다. 별도 설치 없는 실행을 확인한다.
- 서버 기본 호스트는 127.0.0.1, 기본 포트는 8080으로 두고 PORT로 바꿀 수 있게 한다. 테스트는 임시 포트로 격리한다.
- 서버 생성·종료를 Node 테스트에서 호출할 수 있도록 실행 진입과 재사용 함수를 분리한다. 프로젝트 루트 밖 파일을 제공하지 않는다.
- 정적 파일만 제공하며 게임 API는 만들지 않는다. index.html의 type=module 진입점이 눈에 보이는 초기화 표시를 갱신해 ESM 실행을 확인한다.

시연 범위: 로컬 HTTP에서 최소 준비 페이지가 열리고 ESM 초기화 표시가 나타난다. 스도쿠 게임은 아직 없다.
