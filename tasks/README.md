## 생성과 갱신

- [AGENTS.md](../AGENTS.md)의 규칙을 따른다. [task.md](task.md)는 복사용 원본이다.
- 하위·보관 파일, 제목과 이 목록의 사용·예약·삭제 ID를 확인하고 숫자 최댓값 다음 번호를 최소 세 자리로 발급한다.
- 생성 직전 ID·경로를 확인하고 기존 파일을 덮어쓰지 않는 방식으로 생성한다. 같은 ID의 다른 이름도 충돌이다.
- 실제 상태와 목록을 함께 갱신한다. 03은 진행 중, 04에서 조건을 충족한 뒤 완료로 변경한다.
- 상태는 예정 / 진행 중 / 차단됨 / 완료 / 취소이며 보관·삭제 표시는 별개다.
- 삭제·이동 이후에도 ID와 위치·설명을 남기고, 사용한 ID는 재사용하지 않는다.
- 로컬 확인으로 다른 브랜치의 발급을 보장하지 않는다. 팀 공용 ID 규칙을 우선한다.
