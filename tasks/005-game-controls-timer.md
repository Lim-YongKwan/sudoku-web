## 기술 계약과 시연 범위

- 드롭다운은 selectedDifficulty만 바꾸고 다음 NEW_GAME_REQUESTED에서 적용한다. activeDifficulty는 요청·퍼즐의 난이도를 유지한다.
- 새 요청은 이전 AbortController를 취소하고 requestId를 증가시킨다. 현재 요청·상태·난이도와 일치한 성공만 적용하며 오래된 성공·실패는 무시한다.
- 생성 중 보드·숫자 입력은 잠그되 새 게임 재요청은 가능하다. 이전 보드는 제거하고 실패 시 일반 안내·재시도를 제공한다.
- getElapsedSeconds는 시각 차이를 내림해 초로 계산하고 formatElapsed는 mm:ss로 표시한다. 타이머는 준비 후 시작·새 게임 초기화·완료 정지, 표시 주기는 250ms다.
- main에서 interval·이벤트·진행 생성을 정리한다. 숨겨진 탭 시간은 포함하고 다시 보이면 실제 경과 표시로 복구한다. OS 절전·페이지 재실행 간 보존은 범위 밖이다.
- isComplete의 세 조건이 충족될 때만 완료 전이를 하고 native dialog를 연다. 닫기·Escape 지원, 닫은 뒤 새 게임 버튼으로 포커스 복귀한다.

시연 범위: 난이도를 정해 새 퍼즐을 플레이하고 시간·메모·충돌을 확인하며 유효 완성 시 축하 UI를 본다. 실패·연속 재시작도 처리한다.
