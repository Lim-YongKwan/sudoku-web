## 기술 계약과 실제 구현

- styles/main.css: 숫자 글꼴 스택은 "Trebuchet MS", ui-rounded, system-ui, sans-serif. 입력600·단서700, 같은 크기·line-height·Grid 중앙 정렬을 적용했다.
- 셀 배경·색상으로 단서를 보조 구분하며, 메모는400·기존 크기를 유지한다. 오류 !는800이다. 숫자 패드도 같은 서체·600을 쓴다.
- 기본 숫자는 lining-nums/tabular-nums를 요청한다. 지원 여부와 실제 렌더링 서체·지원 굵기는 기기별 확인이 필요하다. 고정 굵기 서체에서는600과700이 같은 실제 굵기로 매핑될 수 있다.
- src·상태·입력·엔진·의존성·빌드/배포 설정은 변경하지 않았다.
- tests/browser/typography.html·typography-checks.js: 1~9 단서/입력·메모, 선택/충돌, 생성, 완료 잠금의 개발 비교 페이지를 추가했다. 실제 퍼즐·완료 검증이 아닌 렌더러 시연이며 dist에는 포함하지 않는다.
- 상세 명령·검증 한계·수동 절차: [008 구현 기록](../docs/typography-008.md).
