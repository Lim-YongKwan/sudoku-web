두 옵션은 readonly 계약으로 선언하고 초기화/NEW_GAME_REQUESTED에서false로 재설정한다. playing에서만 옵션을 바꾸며 난이도·보드·메모·선택·타이머를 덮어쓰지 않는다. 초기 assistance는 복사하고 잘못된 옵션/값은 런타임에서 거부한다.
checkbox는 native label/checked/disabled를 사용한다. 토글 변화는 보드 포커스를 강제 이동하지 않고change listener는dispose에서 정리한다. OFF는 패드 class·남은 수 data 속성·추가 aria-label·도움말을 제거한다.
집계/상태/기존 이벤트 경로에서 별도 제품 코드 결함은 확인되지 않았다. 단, 실제 UI·터치·스크린리더 관찰 전이므로 모든 환경의 가독성/접근성을 확정하지 않는다.
같은 숫자 옵션은 상태 기반만 제공하며 토글·강조 UI는011까지 미노출이다. 010~013 기능과 패키지·빌드/workflow는 추가하지 않았다.
