## 적용한 선택

브라우저 Native ESM, 외부 의존성과 번들러 없음, Node 내장 개발 도구, HTTP 실행,
DOM 독립 엔진과 단방향 상태 흐름, 순차 태스크·브랜치, 독립된 작업·결정 ID와 보존 규칙을 개발 지침에 반영했다.
개발 도구의 프로젝트 기준은 Node.js 22 이상으로 정했다. 이는 새 프로젝트의 개발 기준이며 현재 설치됐다는 뜻이 아니다.
사용자가 실행하도록 지정한 프롬프트의 명시된 선택을 근거로 반영했으며 중복 승인을 요청하지 않았다.

## 실제 확인

- 새 프로젝트 폴더를 생성하기 전 동일 경로가 없음을 확인했다. 기존 파일을 덮어쓰지 않았다.
- node --version: 정상 종료, v16.20.2.
- git --version: 정상 종료, 2.39.1.windows.1.
- 프로젝트에서 git rev-parse --show-toplevel로 Git 루트를 얻지 못했다. 독립된 .git도 없다.
- 다른 담당자의 기존 코드·변경 사항은 이 새 폴더에 없었다.

## 미실행과 남은 준비

- Node 버전 전환·설치, npm 실행, Git 초기화·브랜치·커밋·원격 작업: 미실행.
- Node.js 22 이상 기준을 현재 PATH의 16.20.2가 충족하지 않는다. 새 설치본 확인과 환경 준비가 필요하다.
- 서버·테스트·브라우저 확인: 코드와 설정이 없어 미실행. 검증 통과로 간주하지 않는다.
- 실제 데이터 계약·생성 예산·함수 설계는 01에서 작성한다.
- 새 작업과 결정의 첫 ID 후보는 각각 001이다. 아직 사용·예약된 번호는 없고 실제 생성 직전 다시 확인한다.
