## 범위별 리뷰

- 순수 전이: reducer가 DOM·난수·시계·Promise 효과를 호출하지 않고 입력 Board·배열·Set을 보존한다. 잘못된 payload는 TypeError/RangeError, 금지된 사용자 동작은 동일 상태 참조 no-op다.
- 생성·상태: 더 큰 requestId만 수락하고 생성 성공은 단서 형식·유효성·난이도 빈칸을 확인한다. 오래된 성공/실패·난이도 불일치는 적용하지 않는다.
- 단서·메모: 고정 셀은 선택 가능하나 수정 불가, 메모는 빈 편집 셀에서 토글, 실제 입력/삭제는 해당 셀 메모만 지운다. 초기·복사 Set은 셀별 독립이다.
- 완료: 빈칸·규칙·단서 일치가 모두 충족될 때만 completed이며 시간 메타데이터를 닫는다. completed 입력은 no-op이고 실제 dialog·timer UI는 005 범위다.
- store: 초기 방어 복사·계약상 읽기 전용 getState·독립 구독 token·반복 unsubscribe·변경 시 통지·재진입 dispatch 순서를 검토했다. 외부가 getState를 직접 변조하는 사용은 계약 위반이다.
- 이벤트: root 위임 click·keydown만 등록해 native touch click·button activation을 중복 처리하지 않는다. 게임 키는 셀에서만 처리하고 폼·수정키·Tab·IME를 보존한다.
- 표시·접근성: renderer는 노드를 재사용하고 이벤트 쪽이 선택 셀 focus를 맞춘다. 충돌은 규칙만 검사하며 !·테두리·이름·공용 상태 안내를 제공한다. 실제 보조기기/시각/터치 관찰은 남아 있다.
- main 정리: 페이지 이탈 시 signal·구독·input binding 정리, 캐시 복귀 때 playing/completed snapshot 방어 복사를 검토했다. 실제 BFCache·click·touch 관찰을 이번 테스트로 주장하지 않는다.
- 범위: 정식 timer·dialog·난이도·새 게임 UI는 구현하지 않았다. 외부 의존성·번들러·core의 DOM/Node import는 없다.

## 네트워크 원인 재확인 — 2026-10-26

사용자가 네트워크 오류·긴 대기가 원인일 수 있다며 재시도를 요청해 다음을 수행했다. 앱 코드·테스트 코드는 바꾸지 않았으며 자동 회귀를 다시 실행하지 않았다.

1. Node REPL 호스트에서도 동일 서버 모듈을 실행했다. listen은 성공했지만 같은 런타임의 fetch가 connect EACCES 127.0.0.1로 거부됐다. 브라우저도 타임아웃이었다.
2. 실제 EACCES 근거로 네트워크 권한을 요청했고 이번 턴 범위로 승인받았다. 기존 Node REPL의 fetch는 승인 후에도 EACCES였다. 이 지속 런타임에 권한이 반영됐다고 주장하지 않는다.
3. 해당 서버는 closeServer 후 listening=false를 확인해 정리했다.
4. 승인된 shell 실행에서 새 서버를 띄웠다. http://127.0.0.1:64633/tests/browser/interaction.html에 대한 실제 fetch 응답은 HTTP200이었다. PID40328, 세션57725다.
5. 이번에는 90초 대신 최대10분 유지하고 검증 종료 marker로 해당 서버만 닫도록 했다.
6. 새 브라우저 탭에서 같은 URL로 이동했지만 약247초 뒤 net::ERR_CONNECTION_TIMED_OUT이었다.
7. 브라우저 실패 직후 실행 세션을 확인했을 때 서버 프로세스는 여전히 실행 중이었다. 이번 실패를 90초 서버 만료 탓으로 처리할 수 없다는 근거다.
8. 소유한 retry 서버의 종료 marker만 작성해 정리했고 NETWORK_RETRY_SERVER_CLOSED·exit0을 확인했다.

이번 결과는 서버 시작 실패나 짧은 만료만으로 설명되지 않으며, 실행 환경 사이의 로컬 연결·권한/연결 경로가 문제일 가능성을 뒷받침한다. 정확한 제품 내부 원인이나 브라우저에 권한이 적용됐는지는 확정하지 않는다.
서버 HTTP200은 브라우저의 DOM·click·touch·focus 통과 증거가 아니다. 실제 UI·터치 검증은 계속 미실행이며 004의 차단 상태·미체크 완료 조건을 유지했다.
