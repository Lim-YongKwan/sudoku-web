## 배경과 대안

자동 저장·다중 슬롯·클라우드 동기화는첫 버전 범위를넘는다. 수동 저장은명시한시점으로되돌아간다는행동을명확히한다.
performance.now기준시작 시각을그대로 직렬화하면새페이지에서경과시간이잘못된다.
전체 GameState복원은옵션·취소 기록·요청ID·구독같은일시상태를복원하는문제가있다.

## 결정과 이유

localStorage의버전있는JSON한 슬롯을수동으로저장한다. 기존본덮어쓰기·플레이 중불러오기는확인/취소를 제공한다.
유효저장본이 있으면시작 때이어하기/새 게임을 선택한다. 새 게임은저장본을자동덮어쓰지않는다.
퍼즐/값/메모/난이도/선택/최근 입력/누적경과를복원하고보조 옵션false·history빈값·noteModefalse로시작한다.
저장되지않은진행은복원하지 않는다. 동일 브라우저/origin범위이며기기·도메인·앱간동기화는아니다.
epoch저장일시는표시용,타이머는baseElapsedMs+현재세션단조 시각차이로계산한다. 닫혀있던시간은더하지 않는다.
진행 중인저장만지원한다. 같은gameId게임완료시그슬롯만정리하고다른 게임저장본은보존한다.
스키마·보드·단서·메모·선택·시간을런타임 검증한다. 사용자의현재충돌/틀린값을정답 비교로제거하지 않는다.
저장/복원 실패·취소는현재 게임과기존 저장본을보존하며일반 안내를 제공한다.

## 영향·전환

새 게임식별자·저장효과·복원Action·시작 선택UI·타이머확장이 013에 필요하다. 실제구현 전기존시작/시간/저장없음동작을바꾸지않는다.
D-003의단방향/단서/입력/숨김 탭시간규칙은계속유효하다. 실제 013반영 후그문서에저장범위확장과시간 확장을연결하고전체 대체로표시하지 않는다.
형식 검증의상세·오류별시나리오·gameId수명은후속 계획과 013을 따른다. 브라우저 저장 차단·손상·미지원 버전·이전생성응답경합을 검증한다.
