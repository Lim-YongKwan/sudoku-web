## 발견 사항·해결

| 항목 | 문제·근거 | 수정 또는 보강 | 실제 결과 |
|---|---|---|---|

R1은 실제 재현한 제품 결함이다. R2·R3은 추가로 발견한 제품 결함이 아니라 검증 근거를 보강한 항목이다.
새 API·난이도·예산·유일해 조건은 도입하거나 변경하지 않았다. 새 ADR·후속 태스크 발급은 불필요하다.

## 코드 리뷰 판단

- 보드: dense Array·길이 81·정수 0~9를 검사하며 잘못된 형식은 TypeError다. 행/열/박스 충돌의 모든 인덱스를 포함하고 0은 제외한다.
- 완료: 빈칸·충돌·원본 단서 불일치를 모두 확인하며 모순 puzzle은 false다. 형식 오류는 예외다.
- 풀이·해답 수: 입력 복사, MRV 동률 인덱스 순, 마스크의 배치·복구, solved/unsolvable/invalid 구분을 검토했다. complete/count=1만 유일해며 불완전 count=1을 성공 증거로 사용하지 않는다.
- 생성: 완성 보드 생성 후 섞인 셀 제거마다 완전 탐색 유일해를 요구한다. 개별 제한은 복구·재시도, 전체 제한·취소는 전체 종료다. 성공 결과에 해답, 실패 결과에 puzzle이 없다.
- 예산·반응성: DFS 노드 누계, 탐색 간 전체 예산 공유, 시계 단조성, 전체 남은 시간에 대한 개별 한도, task 양보 후 재검사를 검토했다. 기본 timer가 실제 취소를 처리하는 테스트가 통과했다.
- 경계: core·utils는 상대 ESM import만 사용하고 DOM·Node 전용 import·외부 의존성이 없다. 런타임·난수·시계 주입 오류는 RangeError로 처리한다.
- 불변·격리: frozen fixture, 새 결과 배열, 같은 seed 재현과 동시 호출의 상태 격리를 테스트했다.
- UI·접근성: 이번 작업은 DOM 독립 엔진이므로 적용 대상이 아니다. 브라우저 UI 반응성과 새 게임 취소 연계는 후속 작업에서 확인한다.

## 실제 검증

실행 환경: Windows PowerShell, Node v24.22.1·기존 npm CLI 8.19.4. 세션 PATH에서 lifecycle의 node도 해당 버전을 선택했다.
실행 명령은 [002 구현 기록](engine-002.md)의 명시적 Node·npm CLI 경로와 같다.

1. 수정 전 새 상속 옵션 회귀 검사 1개: 실패 1. 실제 success / 기대 aborted를 관찰했다.
2. 수정 후 신규 검사만 실행: 상속 옵션·개별 시간 제한·독립 기준 풀이 3개 모두 통과.
3. 수정 후 전체 npm test: **43개 / 통과 42 / 실패 0 / 건너뜀 1 / 취소 0**, exit 0. 소요 약 7.75초.
4. 엔진 검사 25개 모두 통과. 기존 서버 18개 중 17 통과·1 skip이다. 정상 CLI 시작·HTTP·소유 부모 IPC 종료·exit 0·포트 닫힘도 이번에 통과했다.

이번 skip은 Windows 환경의 junction 생성 EPERM이다. 통과로 바꾸지 않았다.
이번 서버·runtime·package.json·server.test.js는 변경하지 않았고, 001 완료 이후 이 경로들의 구현 변경도 없다.
[001 사용자 최종 검증](review-001.md)의 전체 18개 통과(링크 검사 포함)와 브라우저·서버 종료 확인을 유효한 이전 증거로 사용했다.
04 지침의 “유효한 이전 실행 결과는 코드·환경 변경 여부를 확인해 근거로 사용할 수 있음”에 따라 현재 17개 재실행 통과와 이전 사용자 확인을 함께 적용했다.
이전 사용자 확인은 이번 도구 실행으로 표시하지 않으며 원시 로그가 미제공이라는 한계도 유지한다. 이번 skip만으로 검증되지 않은 새 엔진 항목을 완료로 바꾸지 않았다.
