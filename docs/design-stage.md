## 주요 계약

- 81셀·0 빈칸, 단서와 현재 값 분리, 입력 불변성과 독립된 메모 집합.
- 유일해는 해답 수 탐색이 완전히 끝나고 count=1인 경우에만 인정. 부분 탐색의 1개는 증거가 아니다.
- 쉬움·보통·어려움 목표 빈칸은 35·45·50. 생성 시도 8회, 전체 1,000,000노드·5초, 개별 탐색 100,000노드·2초, 128노드마다 검사·양보가 초기 설정이다.
- 요청 ID와 취소로 새 게임의 오래된 결과를 무시한다. 타이머는 퍼즐 준비 후 시작·새 게임 초기화·완료 정지이며 숨겨진 탭 시간은 포함한다.
- 상태와 API의 상세 원본은 계획 문서다. 이 기록의 요약이 상세 계약을 대체하지 않는다.

## 현재 구조와 미확인

- architecture.md는 실제 문서 파일이 추가된 사실만 반영했다. 계획된 모듈을 실제 구현으로 기록하지 않았다.
- AGENTS.md는 기존 선택을 보존하고 현재 단계와 실제 생긴 설계 링크를 갱신했다.
- Node 환경은 00에서 확인한 v16.20.2이고 새 확인·설치·전환은 하지 않았다.
- 고정 퍼즐·해답·무해답 후보의 실제 탐색 결과, 생성 성공률·반응성·성능은 B 엔진과 이후 작업에서 검증해야 한다.
- 계획을 막는 미해결 요구사항 질문은 없다. 환경·fixture·성능은 미검증 후속 사항이지 통과 결과가 아니다.

## 01 문서 검증 결과

- 프로젝트 문서 14개와 내부 파일 링크 57개를 확인했다.
- UTF-8, 코드 블록 닫힘, 실제 파일 목록과 문서 구조를 확인했다.
- 보드·탐색·생성·상태·UI·시간 API와 생성 예산 항목이 설계에 포함됨을 확인했다.
- 고정 퍼즐·해답 텍스트의 9행×9자리 형식만 확인했다. 실제 풀이·유일해·성능 검증을 수행한 것은 아니다.
- D-001~D-003의 파일명·제목·목록·채택 상태와 코드 미반영 표시를 확인했다.
- 작업 ID는 사용·예약하지 않았으며 코드·환경 스크립트는 추가하지 않았다.
